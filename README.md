# Spiceworks Help Desk Lab

## Project Summary

In this lab, I simulated a real IT help desk environment using Spiceworks Help Desk. The lab demonstrates ticket creation, assignment, troubleshooting, communication with users, and full ticket lifecycle management from creation to resolution.

---

## Technologies Used

* Spiceworks Help Desk
* Windows Environment (Client + Server)
* Basic Networking (DHCP, DNS)

---

## Lab Overview

This lab replicates a real-world IT support workflow where users submit tickets and technicians troubleshoot and resolve issues.
